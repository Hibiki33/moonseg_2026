候选项全部是"已记录、未采用"。比较规则：一次只改一项，固定种子与训练预算；在场景 5（`dev_train`/`dev_val`）上比较，必要时加场景 6（`dev_val6_train`/`dev_val6`）；除常规指标外单独报告暗帧子集（场景 5 共 357 帧，定义见 [data.md](data.md#验证场景)），并用块长 ≥50 帧的 block bootstrap 估计差异的置信区间。没有稳定增益的选项保持关闭。

| 13 | ViT-H+/16 冻结（840M，从 7B 蒸馏；权重已下载转换，`backbone: vith16plus`） | B→L 已 +7.5，容量上界在哪 | 已有 | 一次训练，显存未实测（先按每卡 4×累积 8） | 低：同一许可与来源 | ADE20K 线性探针 H+ 54.8 与 L 持平，但本域对容量更敏感；7B 仍不做（算力 15 倍以上） |
| 14 | 几何辅助：用来源可核验的通用单目深度/法线模型（如 Depth Anything V2）从官方 RGB 推出伪深度，作辅助监督头、额外输入通道或第二路特征集成 | 阴影中的撞击坑与岩石（场景 9 的失分点） | 无 | 需要新代码与一次训练 | 中：只能用官方 RGB 推出，必须申报来源且模型未见过 LuSNAR 测试场景；公开包的深度/双目/LiDAR 禁用；LuMon 系列深度模型因训练含 LuSNAR 而禁用 | 坑是凹陷、岩石是凸起、阴影只是亮度；LuSeg 的 RGB-D 融合思路 |
| 15 | SegFormer（MiT-B5，ImageNet-1k）作为轻量第二模型 | 便宜的集成成员、来源最干净 | 无 | 新代码 + 一次训练 | 无 | LuSNAR 论文终稿基线中第三（89.96；SAM3 91.48、SAM2 90.15；划分不同） |
| 16 | 几何基础模型特征：Depth Anything 3 / VGGT 的 ViT token（DINOv2 初始化、多视角几何监督），接法由省到贵：(0) 伪深度/法线辅助头（AM-RADIO 式蒸馏，推理不变）；(A) 4 个交互层位把 DINOv3 与 DA3 token 拼通道、线性降维后进现有 Adapter，联合注意力由 Adapter 可变形交叉注意力与 M2F 像素解码器承担；(B) 每层位加 cross-attention，DINO 作 query、DA3 作 key/value（ViT-Adapter/CMX/GeminiFusion 模式）；(C) 两路 token 拼成 8192 序列过 2–4 个联合自注意力块（最易过拟合）；或直接换骨干。token 网格对齐：DA3 输入缩到 896²（patch 14 → 64×64）与 DINOv3 1024²（patch 16 → 64×64）一致，免插值 | 坑/岩石/山体本质是几何，阴影只改亮度 | 无 | 新代码 + 一次训练；双流时每卡 batch 约降到 5–6 | 中：须核对训练数据清单无 LuSNAR/月面测试数据（DA3 晚于 LuSNAR 公开，不能靠时间排除）、权重许可（VGGT 为 CC-BY-NC）并申报 | Depth Anything v1/v2 编码器做分割优于 DINOv2 初始化；VGGT/DA3 特征用于 2D 分割的公开结果待查 |

第一批 L 上的几何增强消融（用户已定，25 轮、无 EMA、无 warmup）：L0 整图对照；L1 ADE20K 式 `random_resize_crop`（1024 基准 × [0.5,2.0]、随机 1024 裁剪、cat_max_ratio 0.75）；L2 温和尺度抖动 0.75–1.25 后裁回/补回 1024。之前以 HRDA 为由不采用 L1 是未经实验的假设，官方配方均以它为主要正则项，且基线出现早期过拟合。不采用：训练集内的岩石 copy-paste（不在规则明文列表中，属中风险，需先在官方论坛确认）。

## 最终流程（方案冻结后）

1. 官方训练包与清单到位（10-22 起）：按 [data.md](data.md#切换到正式清单) 切换到正式清单，重新生成 label_stats。
2. 用选定配方在全部 6 个训练场景上从骨干重训（新配置 `dnv3_va_m2f_<骨干>_final.yaml`，`validate: false`，epoch 数按开发曲线定）。
3. 测试输入到位（11-02）：`predict.sh … --weights-key auto` 加选定 TTA；`tools/package_submission.py` 校验并打包。
4. 11-20 前提交一次；同时准备 train.py/predict.py/权重/配置/环境/README/训练日志/来源说明和 ≤6 页方法文档。

## 红线

- 不读取、不推断场景 2/4/9 的标签；不用测试图像做伪标签、自训练、TENT 式更新或 AdaBN 式统计重估。
- 不引入官方训练材料以外的图像或标注，也不下载使用公开的场景 2/4/9 数据；增强只在官方图像与对应标签上做（[augmentation_research.md](augmentation_research.md#合规)）。
- 预训练权重只用来源可核验的 DINOv3（LVD-1689M），申报来源与预训练数据范围（[weights.md](weights.md)）；不用 COCO-Stuff/Hypersim 等额外分割数据预训练头部，也不用官方 7B Mask2Former head。
- 公开训练场景开发池只用于方法开发，其权重不作为最终模型或其初始化；最终模型在组织方清单上从骨干重训（边界见 [data.md](data.md#公开训练场景开发池)）。
