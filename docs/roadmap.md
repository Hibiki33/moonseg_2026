# 路线记录与候选清单

更新：2026-10-21 晚。主线是**冻结 DINOv3 + ViT-Adapter + Mask2Former 的基线**；本文记录已经确定的事、正在跑的实验、以及之后可选的路线。候选项全部是"已记录、未采用"，采用与否以场景 5（必要时加场景 6）的验证结果决定，并且一次只改一项。

## 已定事项

| 项目 | 决定 | 依据 |
|---|---|---|
| 模型 | DINOv3 ViT-B/16 冻结 + 官方 ViT-Adapter + Mask2Former（100 query、hidden 256、6+6 层） | 用户主线 |
| 输入 | 1024×1024 整图，不裁剪，不垂直翻转/旋转 | 标签与绝对行号强相关（`audit_2026-10-21/data_audit.md`） |
| 有效 batch | 每卡 8 × 2 卡 × 累积 4 = 64（要求不低于 64） | 用户决定 |
| 优化 | AdamW、lr 2e-4、warmup 250、poly 0.9、wd 0.05、clip 0.1、bf16+TF32、EMA 0.999、80 epoch | 平方根缩放 Mask2Former 原配方；待基线曲线确认 |
| 增强 | hflip 0.5；亮度 ±32、对比度 0.5–1.5 各 0.5；像素下限 22 | DINOv3/MMSeg 标准强度 |
| 验证 | 场景 5，每轮评估、隔 2 帧抽样，末轮全量；同时报原始权重与 EMA | 抽样偏差 ≤0.4% |
| 算子 | 官方 MSDeformAttn CUDA 扩展（`scripts/build_ops.sh`） | 快 31%、省 10 GiB，数值一致 |
| checkpoint | 只留 `last.pt`、`best.pt`，不存冻结骨干；`runs` 在本地盘 | 用户决定 |
| GPU | ViT-L 在 PCI 0/7；ViT-B 在 PCI 5/6（`NCCL_P2P_DISABLE=1`） | `gpu_topology.md` |
| 数据 | 官方清单到位前用公开训练场景池开发；最终模型在官方清单上从骨干重训 | `development_pool.md` |

## 最终流程（方案冻结后）

1. 官方训练包与清单到位（10-22 起）：`tools/prepare_data.py --official-allowlist … --validate-labels`，重新生成 label_stats。
2. 用选定配方在全部 6 个训练场景上从骨干重训（新配置 `dnv3_va_m2f_<骨干>_final.yaml`，`validate: false`，epoch 数按开发曲线定）。
3. 测试输入到位（11-02）：`predict.sh … --weights-key auto` 加选定 TTA；`tools/package_submission.py` 校验并打包。
4. 11-20 前提交一次；同时准备 train.py/predict.py/权重/配置/环境/README/训练日志/来源说明和 ≤6 页方法文档。

## 红线

- 不读取、不推断场景 2/4/9 的标签；不用测试图像做伪标签、自训练或测试时自适应。
- 不引入官方训练材料以外的图像或标注；增强只在官方图像与对应标签上做。
- 预训练权重只用来源可核验的 DINOv3（LVD-1689M），申报来源与预训练数据范围；不用 COCO-Stuff/Hypersim 等额外分割数据预训练 head。
- 开发池训练的权重不作为最终模型的初始化。
